GitHub Size Lens

顯示 repo 大小、資料夾內每個檔案的大小，以及單檔下載按鈕。

要顯示哪些東西

打勾就會出現在 GitHub 頁面上，取消打勾就不顯示。改了馬上生效。

GitHub 通行碼（不設也能用）

這個擴充要向 GitHub 查詢大小。GitHub 限制：沒有表明身分的話，每小時只能查 60 次。 平常每看一頁大約用掉 1～2 次，看過的資料 5 分鐘內不會重查，所以一般逛逛通常夠用。

如果常常看到「查詢次數用完了」的提示，或想看私有 repo 的大小， 就到 GitHub 申請一組通行碼（GitHub 稱為 token），貼在下面。設定後每小時可以查 5,000 次。

通行碼只存在這台電腦的 Chrome 裡，不會同步到其他電腦，也只會送給 GitHub。

怎麼申請通行碼？（點開看步驟）
  1. 打開 GitHub 的通行碼申請頁（要先登入 GitHub）。
  2. Token name：隨便取個名字，例如「Size Lens」。
  3. Expiration（有效期限）：選一個期限，例如 90 天。到期後回來重新申請、再貼一次就好。
  4. Repository access（能看哪些 repo）： 只看別人的公開 repo，選 Public repositories，下一步可以跳過。 也要看自己的私有 repo，選 All repositories。
  5. 選了 All repositories 的話：在 Permissions 找到 Contents，改成 Read-only（只能讀、不能改）。其他都不用動。
  6. 拉到最下面按 Generate token，複製產生的那串文字，貼到上面的框框按「儲存」。
    那串文字只會顯示這一次，關掉頁面就看不到了，沒複製到就重新申請一組。
