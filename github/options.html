顯示項目

GitHub Token（選填）

沒有 token 時，GitHub API 每小時只能呼叫 60 次（依 IP 計算），而且看不到私有 repo。 設定 token 後每小時 5,000 次。Token 只存在這台電腦的瀏覽器裡（chrome.storage.local，不會同步）， 也只會送到 api.github.com。

怎麼建立 token？
  1. 到 GitHub → Fine-grained personal access tokens。
  2. Repository access：只看公開 repo 選「Public repositories」；要看私有 repo 就選「All repositories」或指定 repo。
  3. Permissions：私有 repo 需要 Contents: Read-only（Metadata 會自動帶上）。只看公開 repo 不需要任何權限。
  4. 設一個到期日，建立後把 token 貼到上面儲存。

快取

同一個 repo / 資料夾的結果會快取 5 分鐘，以節省額度。
